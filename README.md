# رفيق براعة · Baraa Companion

برنامج ويندوز صغير يرافق المتدرب في دورة «صناعة المحتوى بالذكاء الاصطناعي» (أكاديمية براعة). تظهر شخصية **«قلم»** (قلم قصب بلا وجه) فوق البرنامج الذي يتعلمه المتدرب، وتشير بسنّها على الزر المطلوب، وتشرح وظيفته، وتنتظر أن **يضغطه المتدرب بنفسه**، ثم تحتفل وتنتقل للخطوة التالية. تعمل فوق أي برنامج: تطبيق Claude، المتصفح، أو غيرهما.

## للمتدرب
1. شغّل `Baraa-Companion-Setup-X.Y.Z.exe` (تثبيت لمستخدمك فقط، لا يحتاج صلاحيات مدير).
   - ويندوز قد يعرض «Windows protected your PC» لأن المثبّت غير موقّع تجاريًا: اضغط **More info** ثم **Run anyway**.
2. تظهر لك **قائمة التدريبات** بأسمائها. اضغط «ابدأ التدريب» على أي واحد.
3. اضغط على الأزرار الحقيقية في البرنامج أنت بنفسك. القلم لا يضغط عنك ولا يكتب عنك.
4. **للخروج في أي وقت:** زر ✕ في فقاعة القلم، أو `Ctrl+Alt+Q`، أو أيقونة القلم في شريط المهام. **للتخطي:** «تخطَّ هذه الخطوة» في الفقاعة أو في الشريط السفلي.
5. **التحديث تلقائي:** يفحص البرنامج عند تشغيله، وينزّل الجديد في الخلفية، ويثبّته عند الإغلاق. وتصلك الدروس الجديدة دون إعادة تثبيت.

| الاختصار | وظيفته |
|---|---|
| `Ctrl+Alt+→` أو `Ctrl+Alt+N` | الخطوة التالية |
| `Ctrl+Alt+←` | الخطوة السابقة |
| `Ctrl+Alt+F` | إعادة البحث عن الزر |
| `Ctrl+Alt+H` | إخفاء / إظهار القلم |
| `Ctrl+Alt+Q` | إنهاء الدرس (وإغلاق البرنامج إن لم يكن هناك درس) |

### الخصوصية
- لا يسجّل البرنامج ما تكتبه بلوحة المفاتيح، ولا يلتقط صور شاشة، ولا يرسل شيئًا عنك.
- يقرأ من ويندوز أسماء الأزرار ومواضعها فقط، محليًا على جهازك، ليعرف أين يشير.
- الاتصال الوحيد بالإنترنت: فحص التحديثات والدروس من هذا المستودع على GitHub.
- لا يلمس أبدًا بيانات الدفع أو كلمات المرور، وهذه تكتبها أنت بنفسك.

## للمدرب (وضع المدرب)
اضغط `Ctrl+Shift+T` داخل نافذة القائمة لإظهار «وضع المدرب» (أو شغّل `Start-Companion.cmd --trainer`).
1. اكتب اسم الدرس واضغط **ابدأ التسجيل**، ثم نفّذ الخطوات على الشاشة كما تفعل عادة. يُحفظ كل ضغط باسم الزر ومكانه. (`Ctrl+Alt+K` يضيف «نقطة شرح»، و`Ctrl+Alt+S` يوقف التسجيل.)
2. يفتح المحرّر: اكتب **شرحك العام** للدرس، ثم اضغط **اشرح الخطوات بـ Claude Code**. يستدعي البرنامج Claude Code المثبّت على جهازك (`claude -p`) ليكتب شرحًا مفصّلًا لكل خطوة بلهجة المتدرب، وتعدّل ما تشاء.
3. **جرّب الدرس** لتراه كما سيراه المتدرب، ثم **تصدير للنشر**.
4. حوّل الملف المصدّر إلى `lessons/src/` وانشر (الأسفل).

> تنبّه: أسماء الأزرار في الدرس المسجَّل تُقرأ من شاشتك. راجع الملف قبل نشره حتى لا يحمل اسمًا خاصًا بك (اسم محادثة أو ملف مثلًا).

## الدروس
كل درس ملف JSON في `lessons/src/`، يُجمَّع في `lessons/pack.json` ويُوقَّع بمفتاح Ed25519. البرنامج يقبل حزمة الدروس فقط إذا تطابق توقيعها مع المفتاح العام المضمّن في `src/pack-public.pem`، فلا يستطيع أحد حقن درس مزوّر.

```json
{ "say": "جرّب بنفسك: اضغط زر **Terminal**.",
  "target": { "uia": { "process": "^claude$", "name": "^Terminal$", "type": "Button" } },
  "wait": "click" }
```
- `say` نص الفقاعة (`**غامق**` مسموح) · `hint` سطر صغير · `button` نص زر التالي · `anchor`: `center` | `bottom-left` | `bottom-right`
- `copy`: نص يُنسخ بزر «انسخ الـ Prompt» (يلصقه المتدرب بنفسه)
- `wait`: `next` أو `click`
- `target.uia`: `process` (اسم العملية) و`window` (جزء من عنوان النافذة) و`name` (تعبير نمطي لاسم العنصر) و`type` (`Button|Hyperlink|TabItem|MenuItem|ListItem|Edit|…`)؛ أو `target.win.rel` (نسبة من النافذة للأيقونات بلا اسم)؛ أو `target.fraction` / `target.rect`.

## الإصدار والنشر (للمالك)
```bash
npm install
npm run pack                  # يدمج lessons/src في pack.json ويوقّعه (يحتاج المفتاح الخاص خارج المستودع)
git add -A && git commit -m "lessons: ..." && git push   # الدروس تصل للجميع خلال دقائق، بلا إصدار جديد
npm run dist                  # يبني dist/Baraa-Companion-Setup-X.Y.Z.exe
gh release create vX.Y.Z dist/Baraa-Companion-Setup-X.Y.Z.exe dist/Baraa-Companion-Setup-X.Y.Z.exe.blockmap dist/latest.yml --title "vX.Y.Z" --notes "..."
```
- تحديث **الدروس** فقط: `npm run pack` ثم `git push` (البرنامج يقرأ `lessons/pack.json` و`pack.sig` من فرع `main`).
- تحديث **البرنامج**: ارفع الرقم في `package.json`، ابنِ، وانشر الإصدار على GitHub؛ التطبيقات المثبّتة تنزّله تلقائيًا (`electron-updater`).
- المفتاح الخاص للتوقيع: `%USERPROFILE%\.baraa-companion\pack-signing.pem`. لا يُرفع للمستودع أبدًا. إن ضاع فأصدر نسخة من البرنامج بمفتاح عام جديد.
